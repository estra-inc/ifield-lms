# プロダクト概要

社内研修学習管理システム（LMS） -- エンジニアリングおよびデザイン領域のスキル習得を目的とした社内学習プラットフォーム。

学習者のトラッキングと評価（採点・コーチング等）に専念し、教材・演習問題・模擬案件のコンテンツ管理はGitHub（Docs as Code）に完全移行したアーキテクチャを採用する。

## コアコンセプト

- **学習トラッキング基盤（LMS本体）**: 学習履歴、日報、コーチング予約、採点ロジックを提供
- **コンテンツ管理基盤（GitHub）**: 教材（Markdown）、演習問題（JSON/YAML）、模擬案件の評価基準（JSON）を管理し、GitHub Actions経由でLMSへ自動同期
- **Docs as Code**: LMS側にコンテンツ作成画面は存在しない。コンテンツは全てGitHubリポジトリで管理される

## ロールモデル（3つのアクター）

| ロール | 説明 | 主な責務 |
| --- | --- | --- |
| **User（受講生）** | 学習者 | 教材閲覧、日報入力、演習実施、模擬案件提出、コーチング予約 |
| **Manager（管理者）** | コーチ・メンター | 進捗閲覧、日報リアクション（いいね）。コンテンツ閲覧権限なし |
| **Super Admin（スーパー管理者）** | 運営 | ユーザー管理、招待、採点、期間延長、システム設定 |

重要な権限分離: ManagerはコンテンツテーブルへのSELECT権限を明示的に剥奪されている。

## コア機能

1. **認証・招待制アカウント管理**: Super Adminが招待URL発行、トークン検証による登録フロー
2. **学習サイクル・ターム管理**: 基礎ターム -> 実践ターム（模擬案件着手で自動移行）
3. **受講期間管理（Hard Stop）**: `graduation_date`ベースのアクセス制御。期限切れはダッシュボード以外ロック
4. **Docs as Code同期**: GitHub Actions -> 同期API -> UPSERT処理（論理削除含む）
5. **模擬案件と採点**: 階層別チェックリスト評価、スキルレポート（レーダーチャート）
6. **日報・学習目標**: 月次/週次目標、1日複数回入力可、過去日入力可
7. **コーチング予約**: Google Calendar連携、クレジット制、稼働時間枠管理

## ターゲットユースケース

- 社内エンジニア・デザイナーの体系的なスキル習得
- 管理者による学習進捗のモニタリングとモチベーション支援
- 模擬案件を通じた実践スキルの定量評価

## ビジネスルール（重要な制約）

- 模擬案件の排他制御: `status = 'grading'`の提出がある場合、新規提出不可
- 期限切れユーザーのアクセス制限はMiddlewareレベルで強制
- 同期APIはAPIキー（Secret）で保護
- 全テーブルにSupabase RLS適用
